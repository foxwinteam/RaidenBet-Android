# ⚡ اپلیکیشن اندروید RaidenBet

اپ WebView سایت **raidenbet.com** — بدون نیاز به نصب هیچ برنامه‌ای روی کامپیوتر، با کمک GitHub به‌صورت رایگان فایل نصبی APK می‌سازید.

---

## 📁 این پروژه چیه؟

| فایل / پوشه | توضیح |
|---|---|
| `app/src/main/java/.../MainActivity.kt` | کد اصلی اپ — **آدرس سایت** و **مدت صفحه شروع** اینجاست |
| `app/src/main/res/values/colors.xml` | **رنگ‌های اپ** (پس‌زمینه، طلایی و...) |
| `app/src/main/res/mipmap-*` | آیکون اپ |
| `.github/workflows/build-apk.yml` | دستور ساخت خودکار APK در GitHub |
| `app/build.gradle` | تنظیمات فنی (شماره نسخه، اسم بسته و...) |

---

## 🚀 آموزش گام‌به‌گام ساخت APK (بدون برنامه‌نویسی)

### گام ۱ — ساخت اکانت گیت‌هاب (رایگان)
1. به سایت [github.com](https://github.com) بروید
2. روی **Sign up** بزنید و با ایمیل خودتان حساب بسازید
3. ایمیل تأیید را تأیید کنید

### گام ۲ — ساخت مخزن (Repository)
1. بعد از ورود، روی علامت **+** بالای صفحه و بعد **New repository** بزنید
2. در قسمت نام، بنویسید: `RaidenBet`
3. گزینه **Public** را انتخاب کنید (برای ساخت رایگان و نامحدود APK)
4. روی **Create repository** بزنید

### گام ۳ — آپلود فایل‌های پروژه ⚠️ (مهم‌ترین مرحله)
1. فایل ZIP پروژه را روی کامپیوتر **Extract (استخراج)** کنید
2. داخل مخزن جدید، روی لینک **uploading an existing file** کلیک کنید
3. **تمام محتویات پوشه استخراج‌شده** (یعنی پوشه‌های `app` ،`.github` و فایل‌های `build.gradle` ،`settings.gradle` ،`gradle.properties` و...) را با موس بکشید و داخل صفحه آپلود رها کنید
4. ⚠️ **خیلی مهم:** پوشه‌ی `.github` را حتماً آپلود کنید — بدون آن، APK ساخته نمی‌شود! (اگر ویندوز آن را نشان نمی‌دهد، از منوی View گزینه Hidden items را روشن کنید)
5. صبر کنید تا همه فایل‌ها آپلود شوند، بعد پایین صفحه روی **Commit changes** بزنید

### گام ۴ — ساخت خودکار APK توسط GitHub
1. بالای مخزن، روی تب **Actions** کلیک کنید
2. چند لحظه صبر کنید — GitHub خودش شروع به ساخت APK می‌کند
3. روی آیتم **Build APK** که در حال اجراست کلیک کنید تا مراحل را ببینید
4. حدود **۳ تا ۵ دقیقه** طول می‌کشد؛ وقتی کنار آیتم ✅ سبز آمد یعنی موفق بوده
5. داخل صفحه، بخش **Artifacts** را ببینید و روی **RaidenBet-APK** کلیک کنید تا فایل ZIP حاوی APK دانلود شود (فقط با اکانت گیت‌هاب خودتان قابل دانلود است)

### گام ۵ — نصب روی گوشی
1. فایل APK را به گوشی بفرستید (با کابل، تلگرام ذخیره‌شده، یا دانلود مستقیم)
2. روی فایل بزنید — اندروید می‌پرسد «اجازه نصب از منابع ناشناس؟» → **اجازه بدهید**
3. نصب را کامل کنید — حالا اپ RaidenBet روی گوشی شماست! 🎉

## ✏️ شخصی‌سازی اپ

برای هر تغییر، فایل مربوطه را در گیت‌هاب باز کنید (روی فایل کلیک → آیکون مداد ✏️ → ویرایش → Commit changes). بعد از هر تغییر، GitHub خودکار APK جدید می‌سازد.

### تغییر آدرس سایت
فایل `app/src/main/java/com/raidenbet/app/MainActivity.kt` را باز کنید و این خط را عوض کنید:
```kotlin
const val SITE_URL = "https://raidenbet.com"
```

### تغییر رنگ‌ها
فایل `app/src/main/res/values/colors.xml` را باز کنید؛ جلوی هر رنگ کد hex نوشته شده:
```xml
<color name="gold">#FFB703</color>       <!-- رنگ طلایی برند -->
<color name="bg_dark">#0C1220</color>    <!-- پس‌زمینه تیره -->
```
> 💡 اگر رنگ‌های دقیق سایت raidenbet.com را می‌خواهید، از سایت‌ساز یا ادمین سایت بپرسید و همان‌جا جایگزین کنید.

### تغییر مدت صفحه شروع
در `MainActivity.kt` این خط (۲۰۰۰ = ۲ ثانیه):
```kotlin
const val SPLASH_DURATION = 2000L
```

### انتشار نسخه جدید (آپدیت)
قبل از آپلود دوباره، در فایل `app/build.gradle` این دو خط را تغییر دهید:
```groovy
versionCode 2      // هر بار یکی بیشتر
versionName "1.1"  // شماره‌ای که کاربر می‌بیند
```

## ❓ سؤالات متداول

**سایت داخل اپ باز نمی‌شود / سفید است. چرا؟**
- اینترنت گوشی را چک کنید و با کشیدن انگشت از بالای صفحه به پایین، رفرش کنید
- اگر آدرس سایت عوض شده (دامنه جدید)، آدرس را طبق بخش «تغییر آدرس سایت» به‌روز کنید

**می‌خواهم APK را برای دیگران بفرستم — مشکلی نیست؟**
فایل APK که از Actions دانلود می‌کنید مال خودتان است و آزادانه می‌توانید پخشش کنید.

**خطای App not installed هنگام نصب؟**
نسخه اندروید گوشی باید ۶ به بالا باشد؛ فایل APK را دوباره دانلود و منتقل کنید (ممکن است ناقص منتقل شده باشد).

**هزینه گیت‌هاب چقدر است؟**
برای مخزن Public کاملاً رایگان است.

## 📌 نکته مهم
این اپ صرفاً یک «قاب» (WebView) برای نمایش سایت است و هیچ داده‌ای از شما ذخیره نمی‌کند؛ همه‌چیز (ورود، کیف پول، تراکنش‌ها) مستقیم با خود سایت در ارتباط است. ورود به سایت‌های شرط‌بندی قوانین و محدودیت‌های سنی (۱۸+) خودش را دارد — مسئولیت استفاده با کاربر است.
